## Design Specificity Verdict — 2/10

Content is specific; the design carries none of it.

- `profile.ts:21-22` holds the systems-engineering thesis PRODUCT.md calls "the second differentiator"; `profile.narrative` is referenced nowhere in `src/`. `status`, `location`, `summary`, `narrative` are dead data.
- The H1 ("I like building Agentic Software.") fits any portfolio on earth; the differentiator sits in 16px body copy.
- Shepherd's case study has zero images (`document.images` -> `[]`) for a page claiming "deterministic Cypher path queries to verify architectural boundaries mathematically". Design system has three moves: hairline box, blue chip, mono label.
- The "bento" is `grid-cols-1 md:grid-cols-2` with 4 identical cards — a uniform 2x2, not a bento.
- The uncommitted diff removes the numbers: Shepherd metrics `Zero AST-ADR rule drift` / `Automated PR blocking status checks` -> `Architectural Constraint Enforcement` / `Natural Language to code constraint`; constraints lose the sub-second latency and zero-false-negative lines for lowercase fragments; robotic arm loses `Sub-millimeter position accuracy`. PRODUCT.md Principle 1 says "Evidence beats adjectives" — this commit does the inverse.

Detector scan: CLI = 3 findings, all `overused-font` (`src/styles/fonts.css:2,10`, `src/styles/index.css:12`), exit 2, `index.html` clean. Browser overlay across 4 fresh tabs = 33 logged anti-patterns: `nested-cards` x10, `line-length` x9, `undersized-ui-text` x4, `overused-font` x4, `image-hover-transform` x3, `text-overflow` x2, `all-caps-body` x1. No page errors on any route.

The only thing the deterministic scanner could find wrong with the markup is that the site uses Geist — the default font of the category it is imitating. The `nested-cards` cluster is the same point again: a system whose only separation move is a bordered container will nest containers.

Overlays rendered correctly (yellow rule pills anchored to elements, persistent badge bar); viewport-only, archived at `/tmp/impeccable-b/overlay-*.png`. On `/projects` the `UNDERSIZED FUNCTIONAL TEXT` pills land exactly on the four `Case Study` labels.

False positives: CLI `overused-font` x3 is one decision at three declaration sites; `tests/pipeline/fonts.test.ts:24,25` is non-shipping test fixtures, excluded from the count of 3. `overused-font` as a design verdict is a policy disagreement with the documented `DESIGN.md:39-42` choice.

Convergence: detector `undersized-ui-text` x4 matched the `text-[10px]` labels; `text-overflow` (343px/117px) quantified the truncated captions. Detector-only catch the review missed: reading measure of **85–121 chars/line** across 9 firings on case-study prose (`max-w-4xl` is a scan width applied to a reading surface).

## Overall Impression

Careful, well-built, generically-dressed. The accessibility plumbing is better than most professional work; the case-study IA is genuinely designed. But the visual world says "Vercel changelog", the loudest element is an animation rather than a claim, and the uncommitted diff is subtracting the measurable evidence the site exists to present. Biggest opportunity: the ElevenLabs direction is right, but its own token table breaks the one thing the site currently does better than anyone — fix the palette math and the evidence regression before writing theme code, because "absolute layout invariance" lands a bad token on all four routes at once.

## What's Working

1. The case-study information architecture is the real thing — four-part shape holding over 2,928px, with `vs. {alternative}` trade-off chips forcing a named alternative into every architectural claim.
2. Accessibility plumbing is measurably strong and the contrast is genuinely AAA: `#3f3f46` on `#fafafa` 10.0:1, `#52525b` 7.4:1 (7.0:1 on the `#f4f4f5` hover surface), accent `#1e40af` on canvas 8.4:1, white on `#1e40af` 8.7:1. Reduced-motion honoured in the hero (full headline at 150ms under `reduce`) and for view transitions, with a correct non-View-Transitions fallback.
3. URL-addressable filter via `useSearchParams` with `replace: true` — shareable, back-button-safe, URL state not component state.

### [P1] The primary CTA's focus indicator is invisible, and the skip link is unreachable forward
(a) Measured: primary blue CTA `background-color: rgb(30,64,175)`, and on keyboard focus the outer ring is `rgb(30,64,175)` — same colour as the button. Only a 2px canvas gap is perceptible. White secondary buttons (stops 2-4) get a visible ring from the same rule. Cause: unscoped global rule at `accessibility.css:3-6`; the accent outer ring only works against canvas. Fails WCAG 2.4.13 on every primary CTA on every route.
(b) `main` receives focus on load and after every client-side route change (measured `document.activeElement === MAIN#main-content` in both cases), so forward Tab never reaches the skip link or header nav — first Tab lands on "Explore Projects" at y=362. Skip link is `tabIndex: 0` and first in DOM (`firstFive[0] = 'A Skip to main content'`) but never reachable forwards. Load case root cause: `RouteAnnouncer`'s `isInitialMount` is a `useRef` and StrictMode's double-invoked effect (main.tsx enables StrictMode) consumes the guard on pass one, so the focus branch runs on pass two — dev-only. The route-change focus move happens in every environment.
Fix: scope the ring so accent-filled controls get a contrasting outer ring; make the skip-link path real (reset focus to document start or drop the programmatic focus and let the live region announce); give `<article onClick>` cards a keyboard equivalent (measured `role: null, tabindex: null`) via a stretched link. Command: `/impeccable audit` on src/accessibility/, accessibility.css, BentoGrid.tsx, ProjectsView.tsx.

### [P1] The hero types its headline into a blank first paint, then shifts the page
Measured H1 content: t=0 `""`, t=200ms `"I"`, t=600ms `"I like"`, t=1200ms `"I like buil"`, t=2000ms `"I like building"`. Measured CLS 0.187 mobile / 0.096 desktop, 14-15 shift entries, all hero-attributed. `min-h` reserves one line but the finished headline is two, so the H1 grows 32->55px / 52->96px at ~1.2s and content below jumps 23px / 44px. Mobile `flex-col-reverse` puts a 208px avatar above the headline.
Brand argument: the hero is an unstoppable token stream rendering a headline empty at first paint, while the flagship case study argues machine-generated output must be deterministically verified. The one animation contradicts the thesis.
Fix: render the full H1 always and animate only opacity, or delete it; if kept, reserve two lines and keep the H1 out of any live region; `flex-col` not `flex-col-reverse` on mobile. Command: `/impeccable animate` on HeroNarrative.tsx.

## Before you write a line of the ElevenLabs theme

Computed WCAG ratios on the planned palette:

| Planned pair | Ratio | Verdict |
|---|---|---|
| `--text-muted #78716c` on `--bg-canvas #f7f7f5` | 4.47:1 | Fails AA (4.5:1), far below the declared AAA floor |
| `--text-muted #78716c` on `--bg-surface-hover #f0eee9` | 4.14:1 | Fails AA outright — used at 11px in tag pills |
| `--text-secondary #57534e` on `--bg-surface-hover #f0eee9` | 6.58:1 | Fails AAA (needs 7:1) |
| `--border-subtle #e8e6e1` vs `--bg-canvas #f7f7f5` | 1.16:1 | Effectively invisible |
| `--border-strong #d0ccc4` vs `--bg-canvas #f7f7f5` | 1.49:1 | A boundary you cannot perceive |
| `--text-primary #18181b` on canvas / white on ink | 16.5:1 / 17.7:1 | Excellent |

Spec §1.5 makes hairlines the sole separation mechanism, then specifies a 1.16:1 line. §1.4's "absolute layout invariance" means every regression lands on all four routes at once.
Corrections preserving intent: `--text-muted` >= `#57534e` (7.11:1 canvas), ideally `#5f5851`–`#524b45` if it must sit on the hover surface; `--text-secondary` `#514b46` (7.41:1 hover, 8.01:1 canvas); ~`#aca69c` to reach 3:1 on hairlines. The planned ink focus ring (16.5:1) is excellent — keep it, and it fixes P1-4(a) for free if the accent-coloured outer ring is dropped simultaneously.
